# BigSong Personal Website

A modern personal website showcasing photography, design works, and blog content.

## Features

- Photography portfolio with Unsplash-style masonry layout
- Design works showcase with card layout
- Blog system with MDX support
- Tag-based filtering and search
- Admin interface for content management
- Aliyun OSS integration for image storage

## Tech Stack

- Next.js 13+
- TypeScript
- Tailwind CSS
- Radix UI
- PostgreSQL
- Aliyun OSS

## Development

```bash
npm install
npm run dev
```

## Deployment

```bash
npm run build
npm run start
```
